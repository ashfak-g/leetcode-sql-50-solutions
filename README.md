## 🛠 Key SQL Concepts & Engineering Patterns Mastered

Throughout solving and documenting these 50 problems, the following core database design and query optimization patterns were covered:

### 1. Advanced Joins & Relational Calculus
- **Self-Joins**: Modeling hierarchical relationships (`manager_id -> employee_id`) and consecutive temporal series.
- **Cartesian Products with Cross Joins**: Generating complete matrix comparisons (e.g., matching all students against all exam subjects).
- **Anti-Joins**: Identifying orphan rows using `LEFT JOIN ... WHERE right_table.id IS NULL`.

### 2. Window Functions & Analytic Queries
- **Ranking Functions**: Understanding exact behavioral differences between `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()` for handling ties and dense top-N tiers.
- **Rolling Windows**: Calculating multi-day moving averages and cumulative sums using `ROWS BETWEEN N PRECEDING AND CURRENT ROW`.
- **Partitioning**: Scoping window aggregates across categorical groups without collapsing rows into a single group.

### 3. Aggregation & Conditional Logic
- **Pivoting via Conditional Aggregation**: Replacing multiple scans with single-pass `SUM(CASE WHEN ... THEN 1 ELSE 0 END)`.
- **Relational Division**: Identifying entities that satisfy all conditions in another entity set using `HAVING COUNT(DISTINCT ...) = (SELECT COUNT(*) FROM ...)`.
- **String Aggregation**: Dialect-portable concatenation of multi-row values (`STRING_AGG` in PostgreSQL, `GROUP_CONCAT` in MySQL).

### 4. Query Performance & Optimization
- **Sargability**: Using index-friendly boundary conditions (`date >= '2020-02-01' AND date < '2020-03-01'`) over function-wrapped predicates (`YEAR(date) = 2020 AND MONTH(date) = 2`).
- **NULL Safety**: Proper treatment of SQL three-valued logic using `IS NULL`, `IS NOT NULL`, and `COALESCE()`.
- **Scalar Subquery Wrapping**: Safely yielding `NULL` on missing records instead of returning empty sets.
